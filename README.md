# HDFC-BANK-DCF-MODEL-AND-COMPARABLE-ANALYSIS-MODEL
HDFC Bank DCF Valuation Model is a financial modeling project that estimates the intrinsic value of HDFC Bank using the Discounted Cash Flow (DCF) method and Comparable Company Analysis. The model includes financial projections, valuation assumptions, WACC, peer comparison, and estimated share value to assess the bank’s overall valuation.
